# ByAgenda 📅

O **ByAgenda** é uma plataforma moderna de agendamentos projetada para conectar clientes a estabelecimentos de serviços, como barbearias, salões de beleza, clínicas estéticas e muito mais. Com foco em praticidade e uma experiência premium, o app simplifica a gestão de horários para negócios e a reserva de serviços para usuários.

---

## 🚀 Status do Projeto: **Fase Inicial (MVP)**

Atualmente, estamos estruturando a base técnica do projeto, definindo a arquitetura do Frontend Mobile e preparando o ambiente para o Backend.

## 🛠 Stack Tecnológica

### Frontend Mobile
- **Core**: React Native com Expo
- **Linguagem**: TypeScript
- **Navegação**: React Navigation
- **Arquitetura**: Componentização modular e reutilizável.

### Backend (Em Breve)
- **Runtime**: Node.js
- **ORM**: Prisma
- **Banco de Dados**: PostgreSQL (Supabase)
- **Autenticação**: JWT

## 🏃 Como Rodar o Projeto (Frontend)

1. Clone o repositório:
   ```bash
   git clone https://github.com/joaolira-dev/byagenda.git
   ```

2. Acesse a pasta do frontend:
   ```bash
   cd frontend
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Inicie o Expo:
   ```bash
   npx expo start
   ```
